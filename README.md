# ExBoxPacker

A faithful Elixir port of [dvdoug/BoxPacker](https://github.com/dvdoug/BoxPacker) — a 3D bin-packing and
box-selection engine. Given items and a catalog of boxes, it decides which boxes to use and how to arrange items
inside them (rotation, weight limits, weight distribution, stability, constraints).

Status: under construction (Milestone 1 — domain layer).
